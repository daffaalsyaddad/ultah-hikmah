# Hikmah — Chapter 20 (UI UX Pro Max Version)

Versi alternatif dari website ulang tahun Hikmah Sulianti, didesain menggunakan **UI UX Pro Max** skill.

## Perbedaan dengan Versi Original

| Aspek | Original (PRD) | New UI (Skill) |
|---|---|---|
| Background | Dark plum (#160A14) | Light pink (#FDF2F8) |
| Primary | Hot pink #FF4FA3 | Deep pink #DB2777 |
| Accent | Rose magenta #E92F85 | Gold #A16207 |
| Font Judul | Playfair Display | Great Vibes (script) |
| Font Isi | Inter / Poppins | Cormorant Infant (serif) |
| Suasana | Sinematik, dark, streaming | Romantis, light, elegan |
| Pattern | Streaming catalog | Storytelling-driven |
| Tombol | Rounded-lg (8px) | Rounded-full (pill) |

## Cara Menjalankan

1. Buka `index.html` langsung di browser, atau jalankan static server:
   ```bash
   npx serve .
   ```

## Build CSS

```bash
npm run build:css
```
